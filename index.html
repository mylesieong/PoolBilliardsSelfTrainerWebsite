How it works

  1. Tell it where you are. Skill level, the thing that frustrates you most, and how long you have today.
  2. Practise what it proposes. A guided session, or pick a drill yourself and set your own reps and sets.
  3. Score each set as you go. Potted or missed, set by set — a few taps between racks.
  4. Test yourself periodically. Exams give you a stable benchmark that a single practice session can't.
  5. Read the trend. Weeks of records turn into a clear answer: is this working?

Frequently asked questions

How do I practise pool alone without wasting the session?

Give the session a structure: pick a skill to work on, run a small number of drills for a fixed number of sets, score every set as you go, and record the result. The app does that structuring for you and keeps the record, so you can compare this week against last. There is a longer walkthrough in how to practise pool alone.

Does the app work offline?

Yes. Drills, sessions, exams and your practice history all work with no connection, and there is no account or sign-in. Your records stay on your device — see the privacy policy.

Is it only for 8-ball, or does it suit 9-ball and snooker too?

The drills train the underlying skills — potting accuracy, cue-ball control and position — so they apply to 8-ball, 9-ball, 10-ball and snooker alike. Match tracking lets you log whichever game you actually play.

How long does a practice session need to be?

Guided sessions run from 5 to 60 minutes. A short, scored session beats a long, unfocused one — the record is what makes improvement visible.

How do I know whether I am actually improving?

Take a self-assessment exam periodically. Because an exam is a standardised, repeatable test, the score you get today is comparable with the score you get in a month — unlike the feel of a single practice session. More on this in how to measure pool improvement.
